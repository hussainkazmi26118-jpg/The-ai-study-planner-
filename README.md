
# My AI Study Planner

A beginner-friendly Python project that helps students
create a personalized weekly AI learning plan.

## Features

- Asks for the student's name and AI learning goal.
- Collects study days and daily study hours.
- Calculates total weekly study hours.
- Creates a personalized weekly study schedule.
- Displays the plan in the terminal.
- Saves the plan in `study-plan.txt`.
- Validates basic user input.

## Requirements

- Python 3
- No external packages required.

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   ```bash
   python main.py
   ```

   On some systems, use:

   ```bash
   python3 main.py
   ```

4. Enter your information when prompted.
5. Find your saved plan in `study-plan.txt`.

## Example

If you study 3 days per week for 2 hours per day:

Total weekly study hours = 3 * 2 = 6 hours.
